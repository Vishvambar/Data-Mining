================================================================================
TASK 5: FEATURE SELECTION (INFOGAIN + RANKER) & LINEAR REGRESSION ON HOUSING.ARFF
Dataset: housing.arff
Evaluator: InfoGainAttributeEval | Search Method: Ranker (Top 3 Features)
Model: Linear Regression
Evaluation: Compare RMSE with full feature set vs. top 3 features
================================================================================

--------------------------------------------------------------------------------
STEP 1: LOAD HOUSING.ARFF AND RUN BASELINE LINEAR REGRESSION (FULL FEATURES)
--------------------------------------------------------------------------------
1. Open WEKA Explorer -> Preprocess tab -> "Open file..." -> select "housing.arff".
2. Record Baseline on Full 13 Features:
   - Click the "Classify" tab.
   - Choose: classifiers -> functions -> LinearRegression.
   - Under "Test options", choose "Cross-validation" (Folds: 10).
   - Target attribute: "(Num) class" (Price).
   - Click "Start".
3. Record Full-Feature Baseline Metrics from Classifier Output:
   - Correlation coefficient: ~ 0.85
   - Mean absolute error (MAE): ~ 3.27
   - Root mean squared error (RMSE): ~ 4.88
   - Features used: All 13 input features.


--------------------------------------------------------------------------------
STEP 2: PREPARE DATA FOR INFOGAIN (DISCRETIZE CLASS)
--------------------------------------------------------------------------------
*IMPORTANT WEKA NOTE*: 
"InfoGainAttributeEval" measures information gain with respect to a class, which 
mathematically requires a discrete/nominal class. Since "class" (Price) in housing.arff 
is numeric, we temporarily discretize the class to allow InfoGain to rank features.

1. Go to the "Preprocess" tab.
2. Under "Filter", click "Choose":
   - Navigate: filters -> supervised -> attribute -> Discretize
     (or unsupervised -> attribute -> Discretize).
3. Click "Apply".
   - Notice that the target attribute "class" is now Nominal (binned into discrete price brackets).


--------------------------------------------------------------------------------
STEP 3: IDENTIFY TOP 3 FEATURES USING INFOGAIN & RANKER
--------------------------------------------------------------------------------
Method A: Using the "Select attributes" Tab:
1. Click on the "Select attributes" tab at the top of WEKA (5th tab).
2. Under "Attribute Evaluator", click "Choose" -> select "InfoGainAttributeEval".
   - If prompted: "InfoGainAttributeEval must be used with Ranker search. Use Ranker now?", click "Yes".
3. Under "Search Method":
   - Click on the text box "Ranker" to edit its options.
   - Set "numToSelect" = 3 (to retain only the top 3).
   - Click "OK".
4. Under "Attribute Selection Mode", select "Use full training set".
5. Ensure the target class dropdown is set to "(Nom) class".
6. Click "Start".

7. Read the Output to Find Top 3 Ranked Attributes:
   Typically ranked as:
   Ranked attributes:
     1. LSTAT  (InfoGain score: ~0.50 - 0.60) - % lower status of population
     2. RM     (InfoGain score: ~0.40 - 0.50) - Average number of rooms
     3. PTRATIO or INDUS / NOX (InfoGain score: ~0.30 - 0.35)
   - Note down the top 3 attribute names: LSTAT, RM, PTRATIO.


--------------------------------------------------------------------------------
STEP 4: APPLY FILTER TO RETAIN ONLY TOP 3 FEATURES + PRICE
--------------------------------------------------------------------------------
Now we return to the original numeric dataset to train Linear Regression:
1. Go back to the "Preprocess" tab.
2. Reload original "housing.arff" (so "class" is numeric again):
   - Click "Open file..." -> select "housing.arff" -> click "Open".
3. In the "Attributes" panel:
   - Keep only the top 3 identified features (e.g., LSTAT, RM, PTRATIO) and the target ("class").
   - Tick the check boxes next to all other 10 attributes (CRIM, ZN, INDUS, CHAS, NOX, AGE, DIS, RAD, TAX, B).
   - Click "Remove" at the bottom of the Attributes panel.
4. Verify that only 4 attributes remain:
   - RM (Numeric)
   - PTRATIO (Numeric)
   - LSTAT (Numeric)
   - class (Numeric - Target Price)


--------------------------------------------------------------------------------
STEP 5: RUN LINEAR REGRESSION ON TOP 3 FEATURES
--------------------------------------------------------------------------------
1. Click on the "Classify" tab.
2. Ensure Classifier is "functions -> LinearRegression".
3. Under "Test options", select "Cross-validation" (Folds: 10).
4. Ensure target dropdown is "(Num) class".
5. Click "Start".
6. Record New Metrics:
   - Correlation coefficient: ~ 0.81 - 0.83
   - Mean absolute error (MAE): ~ 3.55 - 3.70
   - Root mean squared error (RMSE): ~ 5.25 - 5.45


--------------------------------------------------------------------------------
STEP 6: COMPARISON TABLE & INTERPRETATION OF RMSE
--------------------------------------------------------------------------------
1. Performance Comparison Table:
   -----------------------------------------------------------------------------
   Evaluation Metric             Full Feature Set (13)     Top 3 Features Subset
   -----------------------------------------------------------------------------
   Features Used                 All 13 predictors         RM, LSTAT, PTRATIO
   Correlation Coefficient       ~ 0.854                   ~ 0.825
   Mean Absolute Error (MAE)     ~ 3.27                    ~ 3.65
   Root Mean Squared Error (RMSE)~ 4.88                    ~ 5.34
   Relative Absolute Error       ~ 48.9 %                  ~ 54.5 %
   -----------------------------------------------------------------------------

2. RMSE Interpretation:
   - Root Mean Squared Error (RMSE) penalizes large prediction errors more severely 
     than MAE because individual errors are squared before averaging.
   - When reducing the model from 13 features down to only 3 features (a 77% reduction in dimensionality):
     * RMSE only increased slightly from 4.88 to 5.34 (an increase of less than 0.5 units / ~$500).
     * The top 3 features (RM, LSTAT, PTRATIO) capture the vast majority (over 68%) of 
       the total variance in housing price.
   - Conclusion:
     * The 3-feature model exhibits high parsimony and efficiency. It avoids noise and 
       multicollinearity, is significantly simpler to interpret, requires far less data 
       collection, yet achieves performance very close to the full model.
